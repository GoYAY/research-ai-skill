**建议采用“先短答题，再读材料，随后明确纠错”的顺序。**课前题控制在3分钟、2—3道，作为阅读引子，不计分。

你担心错误影响记忆，有相关研究可以帮助判断：在一组阅读科普文章的实验中，学生先尝试回答问题，即使答错，随后阅读正确内容后，对这些内容的记忆仍优于把时间全部用于阅读。[Richland等，2009](https://pubmed.ncbi.nlm.nih.gov/19751074/)

不过，题目怎么出很关键。另一项研究发现，预先回答复杂的概念推理题没有改善概念理解，而且部分错误会再次出现。因此，这节课适合**先问文中有明确答案的简单问题，把复杂解释和应用放到阅读之后**。[Hausman与Rhodes，2018](https://doi.org/10.1037/xap0000160)

课前准备：从材料中选出希望学生掌握的三个要点，为每个要点标好答案所在段落。预答题用日常语言，避免让学生凭空猜陌生术语。只选能在课堂内读完、留出讨论时间的篇幅。

| 时间 | 活动 | 可直接执行的做法 |
|---|---|---|
| 0—2分钟 | 导入 | 展示文章标题或配图，说明今天要解释的现象。告诉学生：“先写下你的猜想，读完后再用文章检查。” |
| 2—5分钟 | 独立预答 | 做2—3道简短题，每题一句话。允许写“不确定”，不计分，不公开比较谁答错。 |
| 5—8分钟 | 首轮通读 | 要求：“先看全文在解释什么，读完用一句话概括。”避免只搜预答题的答案。 |
| 8—18分钟 | 带题细读 | 找到预答题对应段落，圈出答案和依据；遇到影响理解的生词做记号。教师巡视并解释必要词语。 |
| 18—28分钟 | 核对与讲解 | 逐题呈现“正确答案＋原文依据＋通俗解释”。学生在原答案旁写完整的修正答案；答对的补上依据。 |
| 28—36分钟 | 理解与应用 | 给一个新例子，让学生判断是否符合文中概念，并说明理由。同桌讨论后，教师核对并解释易混点。 |
| 36—41分钟 | 闭卷回忆 | 合上材料，写出三个核心要点，并用自己的话解释其中一个；教师随后展示答案供修正。 |
| 41—45分钟 | 离堂检查 | 写：“我现在能解释的是____；我仍不清楚的是____。”教师收取，针对共同疑问做最后说明。 |

下面的预答题句式可直接替换方括号后使用，选其中2—3题即可；答案都应在原文中明确出现：

- “你猜，[现象]主要由什么引起？”
- “你猜，[文中描述的过程]发生在什么部位／什么条件下？”
- “你觉得，[两个容易混淆的事物]最主要的区别是什么？”

开场可以直接说：

> “这些内容还没学过，现在不要求答对。请先认真想一想，写下一个可能的答案，也可以标注‘不确定’。等会儿我们用文章中的证据来检查和修改。”

纠错时可以说：

> “文章给出的答案是____，依据在第____段。请把完整答案写在旁边，再补一句：支持这个答案的依据是____。”

**如果学生普遍连题意都读不懂，就先用一句话解释题中的必要词语，再让他们尝试。**把时间留给阅读、解释和修正，比延长猜题更合适。
