**建议这节课采用“简短铺垫→先读材料→合上材料答题→核对纠错→再次回忆”。** 把主要答题时间放在阅读之后。

你担心的“猜错会影响后面的记忆”，并非必然发生：阅读实验发现，先尝试回答，即使答错，随后阅读正确内容，也可能促进学习。[Richland等，2009](https://pubmed.ncbi.nlm.nih.gov/19751074/) 不过，一项直接比较两种顺序的科学文本学习实验发现，先读后答在一周后的记忆测验中表现更好。[2019年研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC6760123/)

结合这节课概念陌生、只有45分钟的情况，我会优先保证学生有充分的阅读、回忆和纠正机会。

课前准备：从材料中选出**两个核心概念和一条主要解释**，作为本课重点；为下面三道题准备简短参考答案，并标出对应段落。

| 时间 | 课堂安排 | 可以直接使用的指令 |
|---|---|---|
| 0—4分钟 | 导入，解释阅读必需的背景词，控制在2—3个 | “今天读完后，我们要能说明：文章解释了什么、关键概念是什么意思、作者怎样作出解释。” |
| 4—15分钟 | 独立阅读，先抓整体意思 | “先通读，再圈出两个关键概念。旁边写一句自己的理解；不懂的地方打问号。” |
| 15—20分钟 | 合上材料，独立回答下方三题 | “用自己的话写，暂时想不起来可以写疑问。写完后我们会回到原文核对。” |
| 20—28分钟 | 重读材料，同桌核对 | “给每个答案找到原文依据，标出段落，再用另一种颜色修改。修改时把正确解释写完整。” |
| 28—36分钟 | 教师集中讲解两个核心概念和主要解释 | 每个概念按“准确解释→具体例子→与相近概念的区别”讲；对学生集中出错的地方，说明正确答案及依据。 |
| 36—42分钟 | 合上材料，再次回忆并组织解释 | “写一段给没读过文章的同学看的说明：文章讲了什么、两个概念怎样联系、有什么例子。”同桌互讲，教师巡视纠正。 |
| 42—45分钟 | 出门条与最后订正 | “选一个核心概念，用一句话解释；再写一个仍不明白的问题。”最后展示核心概念的准确表述，让学生核对。 |

第一次合上材料时，直接使用这三题：

1. **文章主要解释了什么现象或问题？** 用一句话回答。
2. **选择一个核心概念，用自己的话解释，并举出文中的一个例子。**
3. **作者怎样解释这个现象或问题？** 写出两到三个相互联系的要点。

开场可以这样说：

> “今天会有两次合上材料作答，目的是练习把读到的内容想起来。第一次有遗漏很正常，核对时要找到原文依据，把正确解释补完整。”

如果阅读明显超时，就缩短同桌交流，**保留教师纠错和最后一次合上材料回忆**。这样，课堂结束前，每个学生都有机会把正确内容重新说出来。
