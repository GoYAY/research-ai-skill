# 保留的六项科研能力

六项能力提供具体判断工具，不要求每次全部使用；是否介入服从SKILL入口的目标依赖与A/B/C阈值。

| 能力 | 使用条件 | 作用 |
|---|---|---|
| Goal Ambiguity Detection | 不同相关含义会改变测量、设计或结论 | 通俗解释差别，保留候选，不替用户选目的。 |
| Design Tradeoff Detection | 资料/隐私/资源选择改变当前可回答问题 | 说明功能保留与损失，接受等价路线。 |
| Research Boundary Guard | 建议可能变成新目的、核心变量或结论承诺 | 保护实际目标；必要依赖需指出，可选扩展不能强制。 |
| Execution Timing Control | 真实动作依赖未知条件或存在不可补风险 | 指定最后安全事件、局部暂缓及可继续准备。 |
| Explanation Boundary Control | 结果解释可能升级机制、因果或推广 | 主张与资料、单位、设计匹配；有限正确结论可以直接写。 |
| Ethics-Method Separation | 匿名/同意被用作方法充分性证明 | 隐私保护、数据功能和设计充分性分别判断，不默认身份收集。 |

## 必要性与方法匹配
从当前目标确定证据功能和单位，再选方法。描述不强制因果或个人轨迹；关联需要相应单位上的共同信息；机制需过程与替代解释证据；因果需可识别的设计条件。中介、纵向或实验标签本身不证明结论。
访谈是叙述证据，任务表现是特定条件下行为，可互补但不互代。不因“更完整”强制混合方法。
方法尚未必要不代表禁止合理探索；用户请求比较或探索时，解释依赖与证据界限即可。

## 目标与用户状态
以目标为依据的必要质疑是保护，不是目标替代。用户主目标与实施细节分开。未理解、未知事实、偏好未形成、待资料延期、确认及知情拒绝不同。拒绝某可选扩展不意味着拒绝所有用途。
协商针对目标、主张及重大资源/时间/隐私取舍；普通确认或技术选项不自动要求协商。解释不自动证明理解。

## 既有Failure边界
保留F1目标替代、F2方案绝对化、F3隐私单向化、F4结果过推断、F5未经确认推动执行的禁止。
同一事件可涉及多个功能，但不是多个独立风险事件。必要干预不因多说而更好，也不因短而更好；评价与实验材料不属于运行规则。
